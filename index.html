¿Qué es CSS?

CSS es un lenguaje que se utiliza para dar diseño y apariencia a las páginas web, modificando colores, tamaños, letras, fondos y posiciones de los elementos.

¿Qué aprenderé en este curso?

En este curso aprenderás todo lo necesario y obligatorio de CSS, incluyendo Flexbox, Grid, Custom properties, Position, Animaciones, Box Model y más. Al finalizar el curso, serás capaz de crear cualquier layout con CSS y desarrollar tus propias animaciones.

¿Qué es CSS GRID?

CSS Grid es una herramienta de CSS que permite organizar los elementos de una página web en filas y columnas, facilitando la creación de diseños ordenados y adaptables.
